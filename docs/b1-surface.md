# B1 observable surface and evidence map

[Pi revision `e7a0df27c09d11bf4161d3605246cbf57a129cb2`](https://github.com/earendil-works/pi/tree/e7a0df27c09d11bf4161d3605246cbf57a129cb2) is a differential oracle for the B1 observable surface, not a runtime or deployment dependency. Julia Forever is native Julia; Julia code mode runs Julia and plugins are native Julia packages. Experiments and counterfactual evaluations belong in separate packages. The rows are a working inventory of capabilities and test requirements, not a claim that the entire surface is known or that every optional integration must ship.

## Evidence and limits

- **Source inventory:** The pinned Pi Git tree contains 2,477 tracked files. An audit compared the paths, modes, kinds, and object IDs from the archived factory's manifest against `git ls-tree -r` at that revision; all matched. This is a complete inventory of that tree, **not a semantic review** of every file. Counts include documentation, examples, tests, and assets as well as code.
- **Semantic review:** The review basis below and the referenced Pi paths identify the selected material examined in the archived inventory. It does not establish that every file in any listed area was read. Current Julia statements were refreshed from source, tests, and module documentation at the observed revision.
- **Observed Julia revisions:** The source represented by `24efed3fbbfb76ad8d2c215e13b91454924899ce` was inspected for the full map. Its direct successor `fe566a5d73f1fb7b1cc53a7b7e81d0cfcde1f3f4` was inspected for the file-mutation changes. These revisions include a later relative-path fixture correction; their implementation source matches the inspected snapshots. Future source changes must update the corresponding rows and evidence.
- **Subsequent MCP work:** The optional stdio client and its selected tests are described in [MCP stdio](mcp.md). This is narrower than the full MCP row and does not establish a verified B1 revision.
- **Subsequent history work:** At `b7e9742db1ff1fabe634364018d3c6b8d6f23075`, recorded agents can use the executor, and `jf` can inspect, abandon and resume SQLite histories. These changes do not establish full B1 parity.
- **Subsequent transcript fork work:** At `331b208a0a03a2584d17169148d9743e9f53f579`, 62 native fork assertions and two pinned-Pi B1 oracle assertions passed locally on macOS with Julia 1.12.6 and Node 25.1.0. They cover the transcript subset described below, not document forks or full B1 parity.
- **Verified B1 revision:** None recorded. Existing tests and historical module reports describe selected cases, not passing evidence for full B1 at this observed revision. Julia and Pi behavior suites were not run for this inventory; the tree comparison and document checks do not establish behavioral parity.

For each included B1 row, write a traceable contract with concrete inputs, expected outputs/state/effects, supported platform and known divergence. Run Pi and Julia against the same deterministic fixtures in isolated temporary workspaces, homes, credentials and network endpoints.
