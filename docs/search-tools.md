# Search tools

`Find` and `Grep` traverse and search files in Julia; they do not invoke Pi, Node, fd, or ripgrep. Both are registered in the `jf` agent. The optional differential tests compare their output with Pi at the pinned revision using Pi's own search tools and their fd and ripgrep executables.

The comparison gives Pi a temporary agent directory. If `fd` or `rg` is unavailable on `PATH`, Pi may download it into that temporary directory; it does not install tools into the user's Pi configuration.

The tested cases cover relative and absolute paths, `@` and local file URLs, basename and path globs, case handling, literal and regex searches, context, match and result limits, empty and binary files, hidden entries, nested `.gitignore`, `.ignore`, `.git/info/exclude`, repository boundaries, and 50 KiB and 500 UTF-16-unit output truncation. Find honors `.gitignore` outside a repository; grep follows ripgrep's behavior and ignores those rules only inside one. A positive grep glob can override file ignore rules. Pi's implementation searches absolute paths, so a path-bearing grep glob such as `src/**/*.ts` does not match a directory suffix unless it is prefixed with `**/`.

These tests establish selected behaviors, not full parity. Results are visited in sorted depth-first order; fd and ripgrep use their own traversal order, so limit-selected results can differ. Julia's PCRE regex syntax differs from ripgrep's Rust regex syntax and error messages. The glob and ignore parser covers common syntax, but not all escaping, glob classes, ignore precedence, `.git` worktree files, global Git ignores, or overrides that reopen ignored directories. Pi's behavior for unreadable files, binary detection, invalid UTF-8, exotic file URLs, fractional limits, and surrogate-splitting truncation may differ. Files are read in full, and cancellation, custom operations, and structured truncation metadata are not yet supported. This implementation and its differential cases have been run on macOS only; Windows and Linux remain unverified.
