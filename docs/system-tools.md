# Shell and directory tools

`Bash`, `PowerShell`, and `Ls` use Julia and the host shell; Pi and Node are used only by optional differential tests. The command runner captures combined stdout and stderr, returns nonzero exit status as an error, stores truncated output in a temporary file, and exposes the last 2,000 lines or 50 KiB. On Unix, a timeout kills the spawned process group. Windows timeouts return an explicit unsupported result before starting a process until process-tree cleanup is implemented and tested. `PowerShell` is available only on Windows, matching Pi's platform boundary.

The tested Pi cases cover ordinary output, errors, Unix timeout, and output truncation. The implementation does not yet provide streaming updates, asynchronous cancellation, Pi's structured shell output, custom shells, shell hooks, session metadata, or Windows WSL shell transport. Successful commands that leave background descendants running may continue writing to the output file after the parent exits. Directory sorting uses Julia's case-insensitive lexical order, which can differ from Pi's locale-aware collation. Advanced file-tool parity and cross-platform verification remain outstanding. Native search and its remaining differences are described in [search-tools.md](search-tools.md). The current tests were run on macOS; the conditional Windows cases are not evidence of a Windows test run.
