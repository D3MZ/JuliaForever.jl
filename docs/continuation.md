# Continuation

`continue!(agent)` resumes a transcript ending in a user or tool message without adding another input. An assistant tail consumes queued steering before follow-ups, according to the selected queue modes; the default is one message at a time. An empty or system-only transcript returns `:empty`; an assistant tail without queued messages returns `:assistant_tail`. Overlapping calls return `:busy`. Recorded agents persist the continuation transition before dispatch and reject stale or faulted history. The call remains busy through synchronous `agent_end` callbacks.

This is a bounded driver slice. Pi's asynchronous subscriber promises and `waitForIdle()` do not have a Julia equivalent; callbacks execute synchronously. Pi supports arbitrary message batches, while this driver queues text. Executor-backed continuation, automatic compaction on continuation, and Pi's exact error exceptions are not implemented. Additional role validation and full cancellation, tool-search, and compaction differential coverage remain outstanding.
